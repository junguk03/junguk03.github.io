백엔드 개발 경험을 기반으로 **정보보안 전문가**를 목표로 활동하고 있습니다.

AWS EC2와 Vercel 배포 경험을 통해 서버 구조와 취약점을 깊이 있게 이해하며, 공격과 방어를 동시에 학습하고 있습니다. 웹 애플리케이션 보안과 서버 보안 분야에 집중하며, 다양한 보안 영역(웹 보안, 시스템 보안, 암호학)을 폭넓게 탐색 중입니다.

> 개발자의 시각으로 보안을 이해하고, 보안 전문가의 관점으로 시스템을 설계하는 전문가

## Education

- 수원대학교 지능형SW융합대학 정보보호학과 (23학번)

## Focus

| 분야 | 내용 |
| --- | --- |
| 웹 보안 | 웹 애플리케이션의 취약점 분석 및 모의해킹 |
| 시스템 보안 | 서버 인프라 보안 및 취약점 대응 |
| 암호학 | 암호화 기술 및 보안 프로토콜 학습 |

## Security Learning

- **OWASP** — OWASP Top 10 기반 주요 웹 보안 취약점 학습 및 실습
- **Tools** — Burp Suite를 활용한 웹 모의해킹, 프록시 도구를 활용한 취약점 진단
- **Wargame** — OverTheWire Bandit, Natas 등 워게임 풀이 및 분석
- **Study** — 암호학과 네트워크 보안, 기초 이론부터 실무 적용까지
- **Practice** — 직접 만든 프로젝트에 취약점을 삽입하고 분석하는 보안 학습
